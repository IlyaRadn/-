# ИИ-закупки Европы и США

Сайт со сделками по закупке ИИ: что покупали государства, институты ЕС, НАТО и банки, на какую сумму, на какой срок и на каких условиях. По каждой сделке есть ссылка на источник.

**Сайт:** https://ilyaradn.github.io/-/

## Как устроено

| Файл | Что в нём |
|---|---|
| `index.html` | Страница: фильтры, сортировка, карточки сделок |
| `data/deals.json` | Все сделки. Страница читает этот файл при открытии |
| `scripts/validate.mjs` | Проверка файла со сделками перед выкладкой |
| `UPDATE.md` | Инструкция для ежедневного автоматического пополнения |

## Как пополняется

Раз в день облачный агент Claude:

1. ищет новые сделки за последние 10 дней;
2. дописывает их в `data/deals.json` с меткой даты;
3. проверяет файл скриптом;
4. выкладывает изменения в ветку `main`.

GitHub Pages пересобирает сайт примерно за минуту. Новые сделки 14 дней показываются с меткой «Новое».

Если нужно добавить или поправить сделку вручную, правьте `data/deals.json` по описанию полей в `UPDATE.md`. Перед выкладкой запустите проверку:

```bash
node scripts/validate.mjs
```

## Оговорки

- Суммы приведены так, как они указаны в источниках.
- Пересчёт в евро грубый и нужен только для сортировки.
- Если сделки нет в списке, это не значит, что её не было: часть порталов закупок поиск не покрывает.
